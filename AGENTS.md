# RVP Anna Construction & Transport - Agent Guidelines

## Architecture & Code Standards

- Built with React 19, Vite, TanStack Router / TanStack Start, and Tailwind CSS.
- Ensure all components are modular, accessible, and adhere to the design system.
- Maintain clean file separation under `src/components/rvp/`, `src/data/`, `src/lib/`, and `src/routes/`.
- Validate builds with `npm run build` and ensure TypeScript and linting checks pass.
